## 프로젝트 소개

테마파크는 시간대·장소별로 방문객 밀도가 크게 달라지고, 그에 따라 응급상황(부상·사고·건강 이상) 발생 위험도 함께 변합니다. 하지만 안전관리 인력은 한정되어 있어 모든 구역을 동시에 촘촘히 관리하기 어렵습니다.

이 프로젝트는 **방문객 밀도·기상 조건·시설 특성 데이터로 응급상황 발생 확률을 사전에 예측**하고, 위험도에 따라 **순찰 주기·필요 인력·대응 프로토콜을 자동으로 추천**해 안전관리자의 의사결정을 돕는 것을 목표로 합니다. 단순 예측 모델에 그치지 않고, 매표소 운영 · 시설 현황판 · 대응 이력 관리까지 포함한 5개 탭 구성의 통합 안전관리 도구로 설계했습니다.

| 항목 | 내용 |

| 데이터 기간 | 2025-08-01 ~ 2026-07-31 (1년) |
| 총 레코드 | 21,900건 (시설 × 10시간/일 × 365일) |
| 응급 발생률 | 3.82% (836건) |
| 데이터 성격 | 시뮬레이션 기반 가상 데이터 (실제 배포 전 프로토타입 단계) |

## 핵심 기능

웹 대시보드는 5개 탭으로 구성됩니다.

### 탭 1 — 응급 대응 매뉴얼
- 12가지 응급 유형 카드 표시 (낙상·심정지·화상·골절·열사병·충돌사고·식중독·교통사고·알레르기·실신·미아·동물물림)
- 카드 클릭 → 팝업으로 단계별 대응 절차, 투입 인력·장비, 주요 발생 시설, 주의사항 표시
- 직원 호출 버튼 → 호출 완료 시 대응 이력 탭으로 자동 이동

### 탭 2 — 매표소
- 티켓 유형 선택(어른/청소년/어린이), 수량 입력(+/- 버튼, 5·10·단체30 프리셋)
- 발권하기 버튼 → 누적 통계 실시간 반영, 오늘 방문객 통계(분류별), 최근 발권 이력 최대 12건 표시
- 데이터 초기화 버튼, 당일 데이터는 LocalStorage에 저장

### 탭 3 — 위험도 모니터링 (AI)
- 구역 선택(12개 시설), 혼잡도 선택(여유/보통/혼잡/매우혼잡), 현재 조건 다중 선택(폭염/우천/한파/강풍/야간/피크타임)
- `model_risk_table.json` 룩업 기반 위험도 분석 ([모델 아키텍처](#모델-아키텍처) 참고)
- 결과: 위험 점수(%), 위험 단계(안전/관찰/주의/위험), 위험 요인 분석 체인, 예상 응급 유형 Top3, 시설별 장비 현황, 초동 대응 가이드, 인력·장비 배치 권고

### 탭 4 — 시설 현황
- 에코팜 시설 지도 + 12개 구역 클릭 가능(지도 마커 + 범례 오버레이 양쪽 연동)
- 전체화면 보기 버튼
- 하단 실시간 방문객 혼잡도 게이지(매표소 탭 데이터 연동)

### 탭 5 — 대응 이력
- 직원 호출 내역 시간순 목록, 대응완료 버튼으로 상태 변경
- 18:00 이후 마감 배너 자동 표시
- CSV 저장 기능(발생시간·유형·중증도·대응절차·장비·인력·상태 포함) — 당일 응급 이력 전체를 CSV로 내보내기

## 모델 아키텍처

3단계 캐스케이드 구조로 응급 발생 여부 → 유형 → 심각도를 순차 예측합니다.

```
입력 데이터 (28 피처)
        │
   ┌────▼────┐
   │ Stage 1 │  응급 발생 여부 예측 (이진 분류, LightGBM)
   └────┬────┘
        │ P(응급) ≥ 임계값
   ┌────▼────┐        ┌─────────┐
   │ Stage 2 │        │ Stage 3 │
   │ 응급 유형 │        │  중증도  │
   │(12종→5그룹)│       │ (3단계) │
   └────┬────┘        └────┬────┘
        └──────┬───────────┘
               ▼
   Isotonic 보정 확률 → 위험도 스코어
```

```
risk_score = P(응급) × (1 + E[중증도] / 5)
E[중증도] = P(경증)×1.0 + P(중등증)×2.5 + P(중증)×5.0
```

노트북에서 학습·보정된 모델의 출력을 **구역 × 혼잡도 × 조건 조합별로 미리 계산**해 `model_risk_table.json`에 저장하고, 웹 대시보드(탭 3)는 이 파일을 조회만 하는 방식으로 동작합니다. 실시간 추론이 없어 응답 속도가 1ms 이내입니다.

## 룩업 테이블 (`model_risk_table.json`)

탭 3(위험도 모니터링)이 참조하는 사전 계산 결과 파일입니다.

- **입력 키**: 구역(12개 표시 구역) × 혼잡도(4단계) × 조건(폭염/우천/한파/강풍/야간/피크타임 중 다중 선택, 2⁶=64가지 조합)
- **내부 매핑**: 12개 표시 구역은 학습된 6개 시설 유형(모델 ID F01~F06)에 매핑되어 위험도 점수가 산출됩니다. 같은 유형에 속한 구역(예: 오토캠핑장A/글램핑존)은 위험 점수 자체는 동일하고, 예상 응급 유형·장비 현황·초동 대응 가이드 등 텍스트 항목에서 구역별 특성을 구분해 보여줍니다.
- **케이스 수**: 6유형 × 4혼잡도 × 64조건 = 1,536케이스가 원본 계산 단위이며, 12개 구역 표시 기준으로는 3,072케이스에 해당합니다(구역별 상세 안내 문구 포함 시).
- **레코드당 값**: 위험 점수(%, Isotonic 보정 확률 기반), 위험 단계(안전/관찰/주의/위험), 위험 요인 분석 체인, 예상 응급 유형 Top3, 시설별 장비 현황, 초동 대응 가이드, 인력·장비 배치 권고
- **위험 단계 경계값**: 0 · 0.03 · 0.07 · 0.15 · 1 (🟢안전 < 0.03 ≤ 🔵관찰 < 0.07 ≤ 🟡주의 < 0.15 ≤ 🔴위험)

> 생성 스크립트는 `ecofarm_model_pipeline.ipynb`의 마지막 단계에서 학습·보정된 Stage 1~3 모델을 모든 조합에 대해 일괄 실행해 JSON으로 직렬화합니다.

## 모델 성능

클래스 불균형(3.82%)이 심해 ROC-AUC보다 **AP(Average Precision)를 핵심 지표**로 사용합니다.

| 지표 | 점추정 | 95% CI | 비고 |
| --- | --- | --- | --- |
| Stage 1 AP (Test) | 0.0845 | [0.060, 0.120] | 기저율(4.35%) 대비 **1.94배** |
| Stage 1 F1 (Test) | 0.190 | [0.131, 0.250] | |
| Stage 1 AUC-ROC | 0.672 | — | 참고용 보조 지표 |
| Stage 2 (12종) Macro-F1 | 0.294 | [0.178, 0.383] | 5건 미만 희귀 클래스 존재 |
| Stage 2 (5그룹) Macro-F1 | 0.334 | [0.235, 0.432] | 운영 알람용 권장 |
| Stage 3 중증도 Macro-F1 | 0.349 | [0.266, 0.418] | 중증 표본 6건, 보수적 해석 필요 |

확률 보정(Isotonic Regression)을 적용해 scale_pos_weight로 왜곡된 확률을 실제 발생률에 맞게 재조정했습니다. 보정 후 "위험" 등급 판정 건수가 49건 → 34건으로 감소했습니다.

## AI 대응 매뉴얼 & 자원 배치

위험도 스코어에 따라 4단계로 자동 분류합니다. (탭 1·3에서 동일 기준 사용)

| 단계 | 스코어 | 주요 조치 | 필요 인력 |
| --- | --- | --- | --- |
| 🔴 위험 | ≥ 0.15 | 대응팀 즉시 파견, AED 준비, 119 연락 | 3명 이상 |
| 🟡 주의 | 0.07 ~ 0.15 | 30분 간격 예방 순찰, 취약자 모니터링 | 2명 |
| 🔵 관찰 | 0.03 ~ 0.07 | 60분 간격 표준 순찰, 기상 확인 | 1명 |
| 🟢 안전 | < 0.03 | 정상 운영 | 최소 |

**자원 배치 공식** (총 인력 N명 기준, 시설당 최소 보장 0.3명 + 위험도 비례 배분):

```
각 시설 배치 인원 = 0.3 + (해당 시설 위험도 / 전체 위험도 합) × (N - 0.3×N)
```

## 알려진 한계

이 프로젝트는 성능 수치를 부풀리지 않고 한계를 투명하게 공개하는 것을 원칙으로 합니다.

- **가상 데이터 기반**: 현재 모든 데이터는 시뮬레이션으로 생성되었습니다. 성능 지표는 실제 운영 환경의 예측력을 보장하지 않으며, 실제 사고 로그 확보 후 재검증이 필요합니다.
- **6개 시설 유형으로 학습**: 모델은 6개 시설 유형(fac_camping, fac_experience, fac_gate, fac_observatory, fac_playground 등)으로 학습되었습니다. 12개 표시 구역 중 같은 유형에 속한 구역은 기본 위험도 점수가 동일하게 산출되며, 대응 조치·필요 장비 안내로 구역별 특성을 보완했습니다.
- **소표본 신뢰구간**: 테스트셋 응급 사례가 81건뿐이라 Stage 2/3 지표의 신뢰구간이 넓습니다. 특히 5건 미만인 희귀 유형(동물물림·미아·알레르기·화상)과 중증(6건)은 참고용으로만 해석해야 합니다.
- **한파 변수 미반영**: is_coldwave가 학습 기간 내 0건이라 상수 피처로 제거했으며, 추위 관련 위험은 temperature로만 간접 반영됩니다.
- **탭 간 데이터 연동은 부분적**: 매표소(탭 2)의 방문객 통계는 LocalStorage 기반으로 브라우저 세션에 종속되며, 위험도 모니터링(탭 3)의 룩업 테이블과는 아직 실시간으로 연동되지 않습니다.
